# Little Bee

A cheerful spelling-bee practice app with a **Python rules engine running in the browser**, ready for GitHub Pages. The MVP includes 90 original US English grade-one words across Easy, Growing, and Challenge. Grade 1 is a starting point; teacher packs support grades 1–12.

## Run locally

Install Node.js 22+ and run:

```sh
npm ci
npm start
```

Open http://127.0.0.1:4173. On Windows, use `npm.cmd` if PowerShell blocks `npm.ps1`. Alternatively, with Python installed, run `python -m http.server 4173 --directory docs`. The first load needs internet access to download Pyodide. No Python installation or server is needed by children.

## How it works

- Listen to a hidden word; ask for its definition, sentence, or part of speech. Text sentence hints mask the target word; the spoken sentence includes it.
- Type the spelling or speak individual letters, review the transcription, and submit. Saying the whole word does not test spelling. Recognition can mishear letters; confirmation/editing is deliberate.
- Practice allows retries, reveals the word after a correct answer, and shows skipped answers in the final review. At least 80% correct on the first attempt recommends the next difficulty for that grade.
- A mini contest gives one attempt per word, no immediate correctness feedback, and a complete score/answer table at the end. This is a fixed-length solo mock contest, not an official elimination tournament.
- Unseen words are chosen first. Once the pool is exhausted, least recently heard words return. Within each round, words never repeat. Rotation and the last 20 result sets persist on the same browser; clearing storage or switching browsers resets them. New words are not generated by AI: adults can expand the curated bank.
- Round sizes are 5, 10, or 20, capped at the available words for the grade and difficulty. Finishing early marks all remaining words as skipped.

## Publish to GitHub Pages

With Git and GitHub CLI installed, authenticate (`gh auth login --hostname github.com`) then run from PowerShell:

```powershell
powershell -ExecutionPolicy Bypass -File scripts/publish.ps1
```

The script creates a public `kids-spellbee` repository under the authenticated account, pushes the source, and enables Pages from `main` → `/docs`. It refuses to push to an existing repository unless the local origin already matches. Pages may need a few minutes for its first build. Its printed URL is an expected address, not proof a build succeeded: verify the Pages deployment in GitHub before sharing. In Settings → Pages, the source should be “Deploy from a branch”, `main`, `/docs`.

## Add words or grades

Edit `data/grade1.txt`, then run `node scripts/build-words.mjs` to update `docs/words.json`. All meanings and example sentences are original app content; the list is not an official Scripps study list. Adults should review vocabulary for their own curriculum.

Or import a JSON array under **For grown-ups & teachers**. Each entry has this form; provide at least 10 entries in a pack:

```json
{"grade":2,"level":"easy","word":"garden","part":"noun","definition":"A place where flowers or vegetables are grown.","sentence":"We planted seeds in the garden."}
```

Grades are integers 1–12; levels are `easy`, `growing`, `challenge`. Each word is 2–25 English letters. Supply enough words at each level you want to use. Imported words and updates to existing word/grade pairs persist locally, not to GitHub or other devices.

## Architecture and tests

`docs/engine.py` owns validation, deck selection, attempts, scoring, feedback visibility, and difficulty progression. `docs/app.js` bridges Python to the DOM, device speech and local storage. `docs/` is the entire deployable site. Python runs via pinned Pyodide 0.27.7 (WebAssembly); GitHub Pages serves static assets. There is no server backend, account system, or API key. The hidden answers are a learning interaction, not an exam security boundary: client-side source/data can be inspected.

`npm test` executes the actual Python engine through Pyodide, including contest secrecy, retry scoring, advancement, no-repeat rotation, word-pack validation, and other-grade support. GitHub Actions runs the same tests. Preview manually on mobile and desktop; verify speech on actual devices.

## Compatibility and privacy

Use a current browser with WebAssembly enabled. Typing and score review work without microphone recognition. Device speech synthesis depends on installed voices. Speech recognition has limited browser support, may require HTTPS or localhost, and may send audio to the browser vendor's recognition service. The microphone starts only when tapped, requires permission, and never auto-submits. Have a grown-up help enable it. This app does not store audio or send scores to a server. Local storage may be disabled or cleared; the app still works for that visit. Google Fonts and the Pyodide CDN receive ordinary resource requests. This is not an offline app.

## Guidance

The request flow follows [Scripps spelling-bee guidance](https://www.spellingbee.com/rules): repetitions, definitions, sentence examples, and parts of speech. Specific competition rules can vary. See [GitHub Pages hosting](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages), [Pyodide usage](https://pyodide.org/en/stable/usage/quickstart.html), and [browser speech recognition](https://developer.mozilla.org/en-US/docs/Web/API/SpeechRecognition).

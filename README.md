# Little Bee

A cheerful spelling-bee practice app with a **Python rules engine running in the browser**, ready for GitHub Pages. The built-in starter packs include 258 US English Grade 1 lesson words and 80 Grade 2 words across Easy, Growing, Challenge, and Expert. Grade 2 has 20 words per level, each with a curated definition, example sentence, and part of speech. Custom word lists support grades 1–12.

## Run locally

Install Node.js 22+ and run:

```sh
npm ci
npm start
```

Open http://127.0.0.1:4173. On Windows, use `npm.cmd` if PowerShell blocks `npm.ps1`. Alternatively, with Python installed, run `python -m http.server 4173 --directory docs`. The first load needs internet access to download Pyodide. No Python installation or server is needed by children.

## How it works

- Listen to a hidden word; ask for its definition, sentence, or part of speech. Text hints mask the target word; the spoken sentence includes it.
- Type the spelling or speak individual letters, review the transcription, and submit. Saying the whole word does not test spelling. Recognition can mishear letters; confirmation/editing is deliberate.
- Practice allows retries, reveals the word and says "You got it!" after a correct answer, and shows skipped answers in the final review. At least 80% correct on the first attempt recommends the next difficulty for that grade.
- A mini contest gives one attempt per word, no immediate correctness feedback, and a complete score/answer table at the end. This is a fixed-length solo mock contest, not an official elimination tournament.
- Unseen words are chosen first. Once the pool is exhausted, least recently heard words return. Within each round, words never repeat. Word rotation and difficulty changes last for this visit only. Reopening starts a freshly shuffled session. Scores are shown at the end of the round and are not saved. New words are not generated by AI: adults can expand the curated bank.
- Round sizes are 5, 10, or 20, capped at the available words for the grade and difficulty. Finishing early marks all remaining words as skipped.

## Simple activity tabs

**Spelling practice** has a grade, round length, difficulty, and practice/mini-contest choice. The starting round is five words. Results stay available for the current round and can be explicitly downloaded. There are no player names, leaderboard, saved scores, or saved progress. The former profile/progress storage key is removed on load. Only voice preferences are persisted under a separate settings key.

**Learn patterns** adapts the 11 groups in the user-supplied *Phonics Pattern Practice Sheet - One Bee First Grade 2026-27*: short vowels, ending blends, double ll/ck, digraphs, silent E, bossy R, vowel teams, ending Y, plurals, two syllables, and tricky words. The PDF remains outside the public repository. Examples and activity types come from the sheet; explanations are paraphrased and use cautious wording for patterns with exceptions. For example, vowel teams do not always have the same sound, and ending-y rules describe common patterns rather than every word.

Each lesson has spoken examples, a five-question pattern activity with feedback/review, and a five-word hidden-answer spelling round from that pattern's pool. Activity types include sound/spelling-group choices, silent-E makeovers, plural transformations, syllable counts, and missing-letter tricky words. Focused spelling uses the same Python engine as regular practice. All 258 Grade 1 lesson words and 80 Grade 2 starter words have curated definitions, matching example sentences, and parts of speech. Correct pattern-activity answers also say "You got it!"; spoken feedback uses the selected voice and reading speed. All three clue buttons are available in regular practice, mini contests, and focused pattern rounds. Learning examples offer the same clues for the selected word, with additional words under More words to explore. Learning examples are visible; spelling-round answers remain hidden until correct or the final review. Activities and pattern examples work independently of the Python download; focused spelling waits for it.

Expand **Voice & reading speed** before or during an activity. Choose an English voice installed on the device, adjust speed from 0.50x to 1.20x (default 1.00x, normal), and use **Try this voice** for a sample. Voice lists can load after the page opens. An unavailable selected voice falls back to the device's US English/default voice. The previous automatic 0.75x default migrates to normal speed once. Explicitly chosen speeds remain saved. These preferences are the only data remembered across visits.

## Publish to GitHub Pages

With Git and GitHub CLI installed, authenticate (`gh auth login --hostname github.com`) then run from PowerShell:

```powershell
powershell -ExecutionPolicy Bypass -File scripts/publish.ps1
```

The script creates a public `kids-spellbee` repository under the authenticated account, pushes the source, and enables Pages from `main` → `/docs`. It refuses to push to an existing repository unless the local origin already matches. Pages may need a few minutes for its first build. Its printed URL is an expected address, not proof a build succeeded: verify the Pages deployment in GitHub before sharing. In Settings → Pages, the source should be “Deploy from a branch”, `main`, `/docs`.

## Add words or grades

Grade 1 lessons come from `docs/patterns.json`. The Grade 2 starter pack comes from `data/grade2.txt`, using `level|word|part|definition|sentence` rows. Grade 2 moves from short-vowel two-syllable words to vowel teams, endings and suffixes, then tricky spellings and longer words. Its 80 words support all round sizes and both modes. Learn patterns remains the 11 Grade 1 worksheet lessons. Curated clues come from `data/grade1.txt` and `data/pattern-dictionary.txt`. Run `node scripts/build-words.mjs` to build `docs/words.json`; `--check` fails if the compiled bank is stale. The default bank combines the Grade 1 lesson words and the Grade 2 starter pack. Grade 1 words store their lesson IDs; Grade 2 words have no worksheet lesson IDs. When a word appears in multiple lessons, its highest applicable tier wins. Short-vowel words start at Easy (27), blends/digraphs at Growing (86), silent-E/R-controlled/vowel-team/ending-Y words at Challenge (104), and plurals/two-syllable/tricky words at Expert (41). Perfecting Challenge can advance practice to Expert; Expert is the final tier. The Grade 2 pack is an app-curated starting point, not a complete curriculum. All meanings and example sentences are original app content; the list is not an official Scripps study list. Adults should review vocabulary for their own curriculum.

Under **For grown-ups: add your own words**, choose a grade (1-12) and difficulty, then paste comma-separated words or one word per line. For example:

```text
apple, bunny, winter
yellow
hello
```

Use single English words with 2-25 ASCII letters. Uppercase is normalized, duplicates are removed, and blank lines or trailing separators are ignored. Empty lists, spaces inside words, punctuation, digits, HTML, control characters, and non-ASCII lookalikes are rejected. Limits: 12,000 characters, 200 nonempty entries per addition (including duplicates), and 1,000 distinct custom word/grade pairs across the visit. One valid word is enough; a round is capped at the available pool size. Words are added to the chosen grade/difficulty, alongside any starter words already there. Re-adding a word/grade pair updates its difficulty.

Validation runs in the Python engine through the same JSON argument bridge used for scoring. Text is never evaluated as code or inserted as HTML. The complete candidate bank is validated before session state changes; a failed submission keeps existing words intact. Form validation reports errors next to the input. The format check does not verify whether a letter sequence is a real dictionary word.

Words in the built-in dictionary retain their curated clues. For unfamiliar custom words, the form requests a definition, a sentence containing the word, and a part of speech before committing any words. Clues must contain 5-400 characters of plain text without HTML or control characters; parts of speech use a fixed list. The Python engine validates the entire bank, and the same clue buttons are available for these words. Difficulty only advances when the next level has words for that grade. Imported words last for this visit only and are not saved or uploaded. The old JSON file-upload control has been removed; repository word-bank JSON remains an internal app asset.

## Architecture and tests

`docs/engine.py` owns validation, deck selection, attempts, scoring, feedback visibility, and difficulty progression. `docs/app.js` bridges Python to the DOM, device speech and local storage. `docs/` is the entire deployable site. Python runs via pinned Pyodide 0.27.7 (WebAssembly); GitHub Pages serves static assets. There is no server backend, account system, or API key. The hidden answers are a learning interaction, not an exam security boundary: client-side source/data can be inspected.

`npm test` executes the actual Python engine through Pyodide, including contest secrecy, retry scoring, advancement, no-repeat rotation, word-list validation, injection/control-character rejection, input limits, and other-grade support. DOM integration checks exercise both activities for all 11 patterns, regular practice/contest switching, all four difficulties for both starter grades in both modes, spoken success feedback and contest silence, complete clue coverage, custom clue validation, normal-speed defaults, audio settings, and removal of saved progress. GitHub Actions runs the same tests. Preview manually on mobile and desktop; verify speech on actual devices.

## Compatibility and privacy

Use a current browser with WebAssembly enabled. Typing and score review work without microphone recognition. Device speech synthesis depends on installed voices. Speech recognition has limited browser support, may require HTTPS or localhost, and may send audio to the browser vendor's recognition service. The microphone starts only when tapped, requires permission, and never auto-submits. Have a grown-up help enable it. This app does not store audio or send scores to a server. Local storage may be disabled or cleared; the app still works for that visit. Google Fonts and the Pyodide CDN receive ordinary resource requests. This is not an offline app.

## Guidance

The request flow follows [Scripps spelling-bee guidance](https://www.spellingbee.com/rules): repetitions, definitions, sentence examples, and parts of speech. Specific competition rules can vary. See [GitHub Pages hosting](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages), [Pyodide usage](https://pyodide.org/en/stable/usage/quickstart.html), and [browser speech recognition](https://developer.mozilla.org/en-US/docs/Web/API/SpeechRecognition).
